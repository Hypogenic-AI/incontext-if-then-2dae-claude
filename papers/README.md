# Downloaded Papers

## Core: Conditional/If-Then Instruction Following

1. **RuleBERT: Teaching Soft Rules to Pre-trained Language Models** (2109.13006_rulebert_soft_rules_plm.pdf)
   - Authors: Mohammed Saeed, Naser Ahmadi, Preslav Nakov, Paolo Papotti
   - Year: 2021 (EMNLP)
   - arXiv: 2109.13006
   - Why relevant: Directly tests if-then Horn rule following in PLMs via fine-tuning

2. **DMN-Guided Prompting: A Framework for Controlling LLM Behavior** (2505.11701_dmn_guided_prompting_decision_logic.pdf)
   - Authors: Shaghayegh Abedi, Amin Jalali
   - Year: 2025
   - arXiv: 2505.11701
   - Why relevant: Uses structured decision logic (if-then) to guide LLM outputs

3. **TOD-ProcBench: Benchmarking Complex Instruction-Following in Task-Oriented Dialogues** (2511.15976_tod_procbench_condition_action_instructions.pdf)
   - Authors: Ghazarian et al. (Amazon)
   - Year: 2025 (NeurIPS Workshop)
   - arXiv: 2511.15976
   - Why relevant: Core paper on condition-action (if-then) instruction statements in dialogues
